Welcome to leannginx!

If you see this page, the leannginx web server is successfully installed and working. It reads nginx configuration files and is written in Lean 4, compiled to C.

Its request parser, path normalisation, location matching and file mapping are proved correct by lake build: for every request, a file it serves lies under the configured root or alias. See LeanNginx/Spec.lean.

Try /files/ (autoindex), /health (return 200) and a missing page (error_page 404).

Thank you for using leannginx.
